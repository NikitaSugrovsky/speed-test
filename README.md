# internet-speed-test

Консольный скрипт для замера скорости скачивания. Делает 10 последовательных
запросов к указанному адресу, каждый раз дожидаясь полного ответа, и выводит
среднее время запроса, общий объём данных и скорость скачивания.

## Требования

Python 3.8+. Сторонние библиотеки не нужны, используется только стандартная
библиотека.

## Запуск

```bash
python speedtest.py <url>
```

Пример:

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Пример вывода (файл 10 МБ, `https://proof.ovh.net/files/10Mb.dat`):

```
Запрос  1: 10.00 МБ за 1.692 с
Запрос  2: 10.00 МБ за 1.961 с
Запрос  3: 10.00 МБ за 2.043 с
Запрос  4: 10.00 МБ за 2.095 с
Запрос  5: 10.00 МБ за 1.644 с
Запрос  6: 10.00 МБ за 2.285 с
Запрос  7: 10.00 МБ за 1.610 с
Запрос  8: 10.00 МБ за 1.992 с
Запрос  9: 10.00 МБ за 1.680 с
Запрос 10: 10.00 МБ за 2.126 с

Среднее время запроса: 1.913 с
Скачано всего: 100.00 МБ
Скорость скачивания: 43.86 Мбит/с
```

## Как считается

- Время запроса: от начала запроса до полного чтения тела ответа.
- Среднее время запроса: суммарное время всех запросов, делённое на 10.
- Общий объём: сумма байт, прочитанных из тела ответов. Выводится в мегабайтах (1 МБ = 1024 × 1024 байт).
- Скорость скачивания: общий объём, делённый на суммарное время запросов. Единица: **мегабиты в секунду** (Мбит/с, 1 Мбит = 1 000 000 бит).

## Коды выхода

| Код | Значение |
|-----|----------|
| 0 | успешно |
| 1 | ошибка сети или пустой ответ |
| 2 | некорректный адрес |
